favicon 的「N + 圆点」结构好认，值得保留。问题在用色：亮蓝和品红属于已经废弃的旧方向，放在 Almanac 页面里像另一个产品。侧栏只有文字，收起侧栏或在移动端时，品牌就没有可以单独露出的图形。

A · 分件 N 推荐

墨色 N 的两根竖笔各刻一道横向缝，像高达零件上的刻线和分件线，暗示「一块块分色喷涂的装甲」。旧 favicon 的圆点换成落在基线上的藏青方块，读作「N.」，像年鉴里 No. / Vol. 那样的缩写句点，也可以理解成一枚色卡。它延续了「N + 点」的结构，同时遵守零圆角和全站一个藏青的规则。

B · 套准标记

用印刷套准十字线框住衬线 N，强调「年鉴、印刷品」这一面，比较文气。缺点是圆环和零圆角体系冲突，16px 下十字线会糊成一团，而且和喷涂、模型的关系最弱。
